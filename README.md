**Red Team @ Hyundai Autoever** (책임/Professional) — previously Red Team at
**Tossbank**, and Security Researcher at **KRSECURITY**. I do **web hacking and
offensive security**, and I don't stop until I find the bug — I've turned that into
assigned CVEs (WordPress, Apache Airflow), KISA award-winning CTF finishes.

- 🧠 **Binary / memory-safety:** OOB write, integer overflow → heap corruption in file-format parsers, verified with AddressSanitizer
